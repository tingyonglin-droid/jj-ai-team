# jj-ai-team

私人 AI 員工團隊工作區，以「總司令中樞＋人工核准」協助財經研究、內容規劃、成效分析與 App 功能規格。AI 產出草稿與判斷；使用者保留觀點、發布、互動、投資建議與 App 上線的最終決策。

## 第一階段節奏

- 平日：投資晨報、市場風險指標、Threads 草稿、Threads 成效分析、Dashboard 今日摘要。
- 週一：本週 Threads 方向與兩組 IG 題目。
- 週二至週四：IG 文案與圖卡腳本。
- 週五：內容成效週報與下週實驗。
- 每週：一次 App 產品觀察或功能規格。
- 每月：總經判斷與市場風險指標績效復盤。
- 隨時：重大市場事件與創辦人靈感快線。

## 從哪裡開始

1. 先讀 [AGENTS.md](AGENTS.md) 了解全域規則。
2. 依任務讀 [角色索引](roles/README.md) 與 [工作流索引](workflows/README.md)。
3. 使用 [templates](templates/README.md) 複製一份成果格式再填寫。
4. 將風險、復盤與決策保存到 [records](records/README.md)。
5. 任何發布、社群互動、個人化投資建議或 App 上線，都停在人工核准點。

建議第一次手動試跑 [每日投資晨報](workflows/daily-brief.md)，確認研究分層與來源標示，再串接市場風險與 Threads 草稿。

## 目錄

| 目錄 | 用途 |
|---|---|
| `docs/` | 團隊設計、核准政策、來源政策、風險方法與 Dashboard 架構 |
| `roles/` | AI 員工責任邊界與交接契約 |
| `workflows/` | 可逐步執行的日常與週期流程 |
| `knowledge/` | 經使用者確認的長期知識 |
| `templates/` | 可直接複製填寫的成果格式 |
| `records/` | 不覆寫的風險、復盤與決策紀錄 |
| `dashboard/` | 五個分頁的資料契約 |
| `scripts/` | 未來同步、資料與本機驗證工具的安全邊界 |

本專案不修改 `jj-invest-public`，也不存取或修改「Threads數據分析」。
