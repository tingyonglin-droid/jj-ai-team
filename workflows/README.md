# 工作流索引

| 工作流 | 節奏 | 主責 | 主要成果 |
|---|---|---|---|
| [每日投資晨報](daily-brief.md) | 平日 | 總經研究員 | 晨報 |
| [每日 Threads](daily-threads.md) | 平日 | 社群經營員 | 待核准草稿 |
| [Threads 成效分析](threads-analysis.md) | 平日 | 社群經營員 | 表現觀察與實驗 |
| [每週 IG](weekly-instagram.md) | 週一至週四 | 社群經營員 | 兩組長青輪播 |
| [創辦人靈感快線](founder-idea.md) | 隨時 | 社群經營員 | 發布時機建議與輕整理 |
| [市場風險指標](market-risk.md) | 平日；每月復盤 | 總經研究員 | 影子風險報告 |
| [App 產品規劃](app-planning.md) | 每週 | App 設計員 | 產品觀察或規格 |

週一另規劃本週 Threads 方向；週五由總司令整合內容週報與下週實驗。重大市場事件優先於例行題庫工作，但不取消查核與人工核准。任務衝突由總司令列出影響與建議順序，使用者決定。
