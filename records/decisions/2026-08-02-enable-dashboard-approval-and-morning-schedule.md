# 啟用 Dashboard 核准與晨報排程

- 決策日期：2026-08-02
- 決策者：使用者
- 背景：私人 Dashboard 需要依真實美股交易日判斷晨報是否應更新，並讓使用者直接核准晨報與市場風險版本；每日晨報規格與 06:30 啟動、07:10 截止、07:30 前交付的排程已完成討論。
- 選項：方案 A，在 Dashboard 以兩段式按鍵保存逐版本核准事件；方案 B，維持對話中人工核准後再手動寫入紀錄。
- 決定：採用方案 A。私人 Dashboard 僅對晨報與市場風險報告顯示「核准此版本」，使用者再次確認後才保存核准事件；資料新鮮度以版本化 NYSE 交易日曆、台灣週末及 07:30 交付門檻判斷。啟用台灣時間週一至週五 06:30 的晨報流程，07:10 鎖定資料、07:30 前交付待核准成果；美股無新完成交易時段或台灣週末時不產生例行版。
- 理由：使用者明確核准方案 A、按鍵核准設計、交易日與警告規則、完整規格及每日排程；逐版本與二次確認可降低誤核准及舊版核准誤套用到新版的風險。
- 適用範圍：私人 `jj-ai-team` Dashboard、`records/daily-briefs/`、`records/market-risk/`、對應決策紀錄與每日晨報自動流程。不得修改或部署 `jj-invest-public`。
- 生效日：2026-08-03
- 後續檢查日：2026-08-14，檢查至少十個排程日的跳過、有限版、延遲、警告、核准與同步紀錄。
- 關聯文件：`workflows/daily-brief.md`、`workflows/market-risk.md`、`docs/superpowers/plans/2026-08-02-dashboard-approval-trading-calendar-and-morning-automation.md`、`dashboard-site/README.md`。
- 核准事件邊界：一次核准只適用於按鍵上顯示的成果路徑、版本與 SHA-256；不延伸到未來版本，也不代表公開發布、對外引用、投資建議、持股調整、買賣或其他投資行動。
- 同步憑證狀態：尚未授權建立 `SITES_BYPASS_TOKEN` 與 `APPROVAL_SYNC_SECRET`，因此 Dashboard 核准事件可保存於站內 D1，但自動回寫 Git 決策紀錄保持停用；啟用該同步需使用者另行明確授權。
