# 決策紀錄

保存使用者對發布原則、研究方法、角色邊界、產品方向、收費、實作與上線等重要決策。檔名使用 `YYYY-MM-DD-<short-decision>.md`。

每筆至少包含決策日期、決策者、背景、選項、決定、理由、適用範圍、生效日、後續檢查日及關聯文件。若決策改變，新增一筆決策並連回舊紀錄，不覆寫舊決定。

## Dashboard 核准 outbox

Dashboard 的晨報與市場風險核准事件由同步器逐版本驗證來源路徑、版本與內容雜湊後，以 exclusive create 追加決策紀錄。自動紀錄必須保存事件 ID、來源版本與 SHA-256，且只適用於該次明確核准的版本；不代表發布、上線或投資授權，也不延伸到未來版本。

本機同步 manifest 存放在 `.approval-sync/` 並排除於 Git。只有對應決策紀錄已存在於 Git commit 後，才可向 Dashboard 回報 `synced`；內容衝突、雜湊不符或服務憑證缺漏時一律停止同步。
