# 角色索引

| 角色 | 識別碼 | 核心使命 | 主要交接 |
|---|---|---|---|
| 總司令 | `commander` | 統籌、分派、驗收與核准摘要 | 使用者、全部角色 |
| 總經研究員 | `macro-researcher` | 研究、晨報、風險指標與復盤 | 總司令、社群、App |
| 社群經營員 | `social-operator` | 草稿、內容分析、IG 與靈感 | 總司令、使用者 |
| App 設計員 | `app-designer` | 產品觀察與功能規格 | 總司令、使用者 |

## 新增角色

1. 使用小寫英文連字號建立 `roles/<role-name>/`。
2. 依既有結構建立 `ROLE.md`。
3. 在本索引登記使命與交接。
4. 將角色加入需要的工作流，不把流程細節寫進角色手冊。
5. 檢查人工核准、資料位置與既有角色是否重疊；由使用者核准新邊界。
