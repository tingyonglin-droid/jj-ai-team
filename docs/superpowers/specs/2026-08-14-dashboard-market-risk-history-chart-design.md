# Dashboard 市場風險歷史曲線圖設計

## 狀態與範圍

- 狀態：待使用者審閱
- 文件日期：2026-08-14
- 主責角色：App 設計員
- 資料語意確認：總經研究員既有市場風險方法與報告欄位
- 任務級別：Feature

本功能讓私人 Dashboard 使用者看見每份市場風險報告對「未來 1–4 週市場下行風險」的評分如何隨報告日期改變。第一版只規劃 Dashboard 資訊呈現，不修改、執行、部署或發布 `jj-invest-public`，也不改變市場風險評分方法。

## 問題與目標

現有市場風險資料契約包含當期分數、趨勢及歷史紀錄，但尚未定義歷史曲線的選版、核准狀態及異常呈現。使用者需要快速回答三個問題：

1. 目前的 1–4 週風險比四週前高或低？
2. 風險何時轉折或跨越狀態區間？
3. 最新資料是否已核准、是否足夠完整且新鮮？

成功標準先視為待驗證的產品假設：使用者可在 10 秒內回答以上問題。尚無真實使用數據，因此不宣稱此功能已改善判斷或投資結果。

## 用戶故事

身為私人 Dashboard 使用者，我希望查看最近四週的 1–4 週市場下行風險曲線，並能追查每個轉折點的原因、證據與資料品質，以便理解風險判斷的變化，而不把它誤認為市場漲跌預測或個人化投資建議。

## 採用方案

採用「單一風險曲線＋風險狀態背景區間」。相較純曲線，背景區間可直接表達分數語意；相較同時繪製 AI 信心及資料完整度，單一主線不會把不同概念誤認為可直接比較的三種風險分數。AI 信心與資料完整度放在節點詳情，而非另畫主線。

## 畫面與互動

### 主圖

- 圖表標題固定為「未來 1–4 週市場下行風險」，副標示明「0–100；不是市場漲跌預測」。
- X 軸為報告的 `as_of` 日期，保留原時區語意；Y 軸固定為 0–100。
- 預設顯示最近四週，可切換「全部歷史」。最近四週以最新有效報告的 `as_of` 為終點，往前推 28 個日曆日，不以使用者開啟 Dashboard 的當下時間計算。
- 休市日或沒有報告的日期不補值、不插值；曲線只連接真實報告節點。
- 待核准節點使用空心點，已核准節點使用實心點。`draft`、`returned`、`blocked` 不偽裝成上述兩種狀態，並依 Dashboard 共同狀態規則顯示清楚標記。

### 背景區間

依 `docs/risk-score-methodology.md` 顯示淡色背景：

| 分數 | 狀態 |
|---:|---|
| 0–20 | 低 |
| 21–24 | 保留區間 |
| 25–40 | 偏低 |
| 41–44 | 保留區間 |
| 45–60 | 中性 |
| 61–64 | 保留區間 |
| 65–80 | 偏高 |
| 81–84 | 保留區間 |
| 85–100 | 高 |

保留區間使用中性色，不自行推定狀態。顏色只是輔助，所有區間均有文字標籤，不能只靠紅綠色區分。

### 節點資訊

桌面版游標移到節點時顯示：

- 報告日期與資料截止時間
- 風險分數及較前次有效節點的變動
- 風險狀態
- 文件版本
- 核准狀態

點擊節點後開啟詳情，顯示：

- 分數改變原因
- 三項主要風險
- 支持證據與反方證據
- AI 判斷信心
- 資料完整度
- 最後更新時間
- 該日其他版本的唯讀入口

手機版不依賴懸停；點擊節點後以底部面板呈現相同資訊。鍵盤使用者可逐點聚焦並開啟詳情。

## 資料規則與版本選擇

唯一資料來源為 `records/market-risk/` 的版本化報告，不由圖表重新計算風險分數。

每個節點至少需要以下正規化欄位：

| 欄位 | 用途 |
|---|---|
| `id` | 穩定識別節點 |
| `as_of` | X 軸日期與時間 |
| `score` | Y 軸 0–100 分數 |
| `state` | 分數語意 |
| `status` | 節點核准樣式 |
| `version` | 同日版本選擇與回看 |
| `change_reasons` | 詳情中的改變原因 |
| `risk_types` | 三項主要風險 |
| `supporting_evidence` | 支持證據 |
| `counter_evidence` | 反方證據 |
| `ai_confidence` | 詳情與警示 |
| `data_completeness` | 詳情與低完整度警示 |
| `updated_at` | 新鮮度判斷 |
| `source_refs` | 回到原始報告 |

同一個 `as_of` 日期存在多個版本時，主曲線只採檔名版本號最高且可解析的版本，不因核准狀態退回舊版；同日其他版本仍可從詳情回看。若最高版本無法解析，該日不靜默退回舊版本，必須顯示版本受阻警示，以免錯把舊判斷當作最新判斷。

較前次變動以畫面範圍內或範圍前最近一個有效節點計算，因此四週範圍的第一個節點若有更早歷史，仍可顯示正確前次變動。

## 異常與限制狀態

- 少於兩筆有效報告時，不畫具有趨勢暗示的連線；顯示單一節點及「歷史資料不足」。
- 完全無有效資料時，顯示空狀態與缺失來源，不顯示 0 分。
- 資料完整度低於 70% 時，節點加警示符號並顯示缺口；不得隱藏該節點。
- 資料過期、來源衝突或風險指標受阻時，在圖表上方顯示警示與影響範圍。
- 單筆非最新版本損壞不影響主曲線，但需在該日版本清單標示無法讀取。
- 單筆最新版本損壞時，該日期不畫節點並顯示版本受阻；其他日期仍正常顯示。
- 分數超出 0–100、日期無法解析或必要欄位缺失時，視為無效資料並記錄可追查錯誤，不自動修補或猜測。

## 架構與資料流

1. Dashboard 資料產生器讀取 `records/market-risk/`。
2. 解析器將每份報告轉為既有 Dashboard 共同欄位與本功能需要的歷史節點欄位。
3. 版本選擇器依 `as_of` 分組，選出最高可識別版本；最高版本解析失敗時產生 blocker，不回退。
4. 圖表資料層輸出按 `as_of` 排序的節點、同日版本清單及警示。
5. 呈現層套用四週／全部歷史篩選、背景區間、節點狀態及詳情互動。

資料解析、版本選擇與視覺呈現分開，讓格式錯誤、選版規則及圖表互動可獨立測試。

## 驗收與測試

- 四週篩選以最新有效 `as_of` 往前 28 日，邊界日期包含在內。
- 「全部歷史」包含所有日期的主曲線節點。
- 同日多版本只繪製最高版本，並可回看其他版本。
- 最高版本損壞時不回退舊版，顯示受阻且保留其他日期。
- 待核准為空心點、已核准為實心點，其他狀態不混用。
- 五種風險狀態及四段保留區間完全符合權威方法文件。
- 休市與缺報日期不產生虛構節點或插值。
- 少於兩筆、完全無資料、低完整度、過期、來源衝突及壞資料都有明確狀態。
- 詳情能顯示正反證、信心、完整度、版本與資料時間。
- 桌面鍵盤及手機點擊均可開啟節點詳情；文字與形狀可在無顏色情境下辨識狀態。
- 不顯示 Beta、持股、再平衡、買賣動作映射或個人化投資建議。

## 非目標

- 不新增 1 週、2 週、3 週、4 週四條預測線；現有分數本身就是單一的 1–4 週觀察期評估。
- 不把 1–3 個交易日即時風險或 1–2 季結構性風險轉成數值曲線。
- 不在圖表中重算、平滑、插值或回測分數。
- 不改變風險方法、狀態門檻、報告排程或人工核准規則。
- 不修改或部署 `jj-invest-public`，也不自動觸發任何投資動作。

## 風險、依賴與人工核准

- 現有報告為 Markdown，實作前須確認資料產生器可穩定解析所需欄位；未知技術限制不在本規格中假定為已解決。
- 市場風險影子運行歷史較短，第一版曲線可能只有少量節點，必須保留資料不足提示。
- 使用者需另行核准實作、測試、Dashboard 部署及任何對外呈現。
- 本規格核准不等於核准市場風險報告內容，也不等於授權發布、上線或投資操作。
