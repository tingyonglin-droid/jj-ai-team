# Dashboard 晨報全文與歷史閱讀設計

## 目標

讓使用者在既有私人 Dashboard 內閱讀完整晨報，並依日期與版本追溯歷史。首頁仍維持快速摘要；全文頁只提供閱讀，不新增核准、發布或投資操作。

## 範圍

- 首頁晨報摘要卡加入「查看全文」。
- 待核准中心的晨報項目加入「查看全文」，其他成果類型不顯示。
- 主選單加入「晨報全文」。
- `/briefs` 顯示歷史晨報，每個日期只列最新版。
- `/briefs/[date]` 顯示該日完整晨報，預設最新版，並可切換同日舊版本。
- 沿用既有登入保護及私人 Sites 專案。
- 第一版不做搜尋、分頁、核准操作或每日排程。

## 權威來源與資料流

`records/daily-briefs/*.md` 是唯一權威來源。Dashboard 資料產生器在部署前讀取並驗證 Markdown，將有效晨報轉為安全的結構化區塊，再寫入唯讀快照；正式站不直接讀取工作區檔案。

每份全文資料保留：

- 日期與版本
- 標題、短摘要與完整內容區塊
- 成果狀態與資料新鮮度
- 資料截止、更新時間、相依項目與原始來源路徑
- 是否為該日最新版

結構化內容支援標題、段落、無序／有序清單、表格與安全連結。Markdown 內的原始 HTML 不執行。

## 最新版與歷史版本規則

- 歷史列表依日期由新到舊排列。
- 同一日期只列最高有效 `vNN`。
- 全文頁保留該日所有有效版本，版本選擇器清楚標示目前版本。
- 新版格式錯誤時不取代最後有效版本；錯誤來源加入既有 blocker。
- 日期或版本不存在時顯示空狀態，不改顯示其他晨報。

## 畫面設計

### 歷史列表

每張卡片顯示標題、日期、版本、狀態、資料截止、短摘要與「查看全文」。列表第一版不分頁。

### 全文頁

頁首顯示返回歷史、標題、日期、版本、狀態、資料截止及版本切換。正文依原始文件順序顯示風險儀表、五則事件、表格、反方證據、來源與人工核准狀態。手機版採單欄，寬表格可水平捲動。

## 權限與安全

`/briefs` 與 `/briefs/[date]` 必須先通過既有 ChatGPT 身分及允許名單驗證。未授權回應不得包含晨報標題、摘要、來源或其他私人內容。部署不得修改允許帳號、登入政策或環境祕密。

## 驗收

- 資料測試：日期分組、最新版選擇、舊版本保留、壞格式回退與 blocker。
- 解析測試：標題、段落、清單、表格及安全連結。
- 畫面測試：主選單、首頁與待核准按鈕、歷史列表、全文及版本切換。
- 權限測試：未授權者無法取得列表或全文。
- 發布驗證：型別、程式碼檢查、完整測試、正式建置與三個既有頁面回歸通過。

## 非目標

本功能不修改晨報研究內容、風險評分方法、核准規則、外部發布流程或 07:30 自動排程。
