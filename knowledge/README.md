# 長期知識庫

此處只保存經使用者確認、可跨任務重用的穩定知識，不保存每日研究、草稿或事後改寫的歷史判斷。

| 文件 | 使用時機 |
|---|---|
| `investment-philosophy.md` | 所有研究、風險與內容任務 |
| `beta-system.md` | App、Beta、再平衡相關規格 |
| `app-product.md` | App 產品觀察與功能規格 |
| `writing-style.md` | Threads、IG 與創辦人靈感 |

新增或修改知識前，記錄來源、使用者確認日期與適用範圍。未知內容標示「尚未提供」，不可由 AI 猜測。短期假說留在任務成果；正式決策留在 `records/decisions/`。
