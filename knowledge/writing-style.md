# 寫作風格

## 已確認原則

- 保留使用者的語氣、市場觀點與人味，只做必要整理。
- 不虛構個人經歷、情緒、對話、績效或曾經採取的投資行動。
- 生活與投資靈感只輕度整理，可判斷立即發、補強後發或放入題庫。
- 不強迫每篇內容加入 App CTA。
- 草稿必須清楚標示尚待使用者補入的個人觀點。

## Threads 已確認寫作特徵

- 常以讀者問題、反直覺結果、數據差異或當下市場焦慮開場。
- 第一人稱明確，常用「我怎麼做／我看什麼／我不做什麼」建立可信度。
- 偏好短段落、逐點列舉、數字、括號與符號，讓複雜概念容易掃讀。
- 常用結構為：提出常見看法 → 提供數據或框架 → 說明個人選擇 → 補上風險與限制。
- 最具辨識度的語氣是工程師式的數據與系統思維，加上全職投資與家庭生活的個人脈絡。
- 高表現內容不全靠情緒或強烈立場；「可執行、可比較、可保存」是較穩定的共同點。
- 不因過往高成效而機械複製誇張數字、反直覺標題或個人經歷；每篇仍須符合真實資料、當下情境與使用者原意。

- 投資策略 30%
