# 成果資料契約

## 用途

回答研究、內容與產品工作是否改善，以及哪些做法應保留、停止或再測試。

## 必要資料

| 欄位 | 型別 | 來源 | 更新頻率 |
|---|---|---|---|
| `weekly_content_reviews` | array | `records/reviews/` | 每週 |
| `monthly_risk_reviews` | array | `records/reviews/` | 每月 |
| `research_accuracy` | object/null | 月度研究復盤 | 每月 |
| `content_experiments` | array | 內容週報 | 每週 |
| `product_learning` | array | App 觀察與決策 | 每週或決策後 |
| `decision_followups` | array | `records/decisions/` | 檢查日 |

成果必須保留基準、觀察窗與資料限制。沒有足夠資料時顯示「尚不能判定」，不得以單篇內容、短期市場漲跌或未驗證假設宣稱成功。
