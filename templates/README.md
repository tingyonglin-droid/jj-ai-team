# 模板索引

複製模板到對應成果位置後填寫。`[請填寫：…]` 是明確輸入欄位；無資料時寫「未取得」並說明影響，不刪除必要章節。完成後保留版本、來源與核准狀態。

| 模板 | 用途 |
|---|---|
| `daily-brief.md` | 每日投資晨報 |
| `threads-draft.md` | Threads 待核准草稿 |
| `instagram-carousel.md` | IG 輪播文案與視覺腳本 |
| `content-weekly-report.md` | 週五內容成效與實驗 |
| `market-risk-report.md` | 每日影子風險紀錄 |
| `app-feature-spec.md` | App 功能規格 |
